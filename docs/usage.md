# 사용 안내

## 화면 영역과 OCR

`임시 영역 선택 → 임시 영역을 확정 → 인식 후 복사` 순서로 사용합니다.

1. `영역` 탭에서 **임시 영역 선택**을 누릅니다.
2. 어두워진 화면에서 텍스트를 드래그해 선택합니다.
3. 테두리 핸들을 드래그해 크기를, 내부를 드래그해 위치를 조절합니다.
4. `Enter`로 선택을 완료하거나 `Esc`로 취소합니다.
5. **임시 영역을 확정**을 누른 뒤 **인식 후 복사**를 누릅니다.

인식 결과는 클립보드에 복사됩니다. 번역 오버레이 모드에서는 같은 버튼이 **번역 후 표시**로 바뀝니다. 텍스트 주변에 여백을 조금 포함하면 너무 작은 영역 때문에 인식이 실패하는 것을 줄일 수 있습니다.

| 영역 탭 기능 | 동작 |
|---|---|
| 임시 영역 선택 | 새 영역을 선택합니다. 임시 영역이 있으면 그 위치에서 조절합니다. |
| 현재 임시/확정 영역 보기 | 임시 영역은 파란색, 확정 영역은 빨간색으로 표시합니다. `Esc`로 닫습니다. |
| 임시 영역을 확정 | 임시 영역을 실제 인식에 사용할 영역으로 등록합니다. |
| 실시간 OCR 시작/중지 | [시작 조건](translation.md#실시간-ocr)이 충족되면 확정 영역을 반복 인식·번역합니다. |

## 북마크

**확정 영역을 북마크에 추가**를 눌러 이름을 지정합니다. 같은 이름이 있으면 덮어쓸지 확인합니다. 북마크는 `bookmarks.txt`에 저장되며, 임시 영역만 선택한 상태에서는 저장할 수 없습니다.

**북마크 영역 불러오기**에서 이름을 더블클릭하거나 `Enter`로 선택하면 임시·확정 영역에 모두 적용됩니다. 바로 OCR을 실행할 수 있습니다. 조정이 필요하면 **임시 영역 선택**으로 수정하고 다시 확정하세요.

## 분리된 버튼 창과 단축키

`행동` 탭의 **'인식 후 복사' 버튼 분리하기**는 버튼만 있는 작은 별도 프로세스 창을 엽니다. 번역 오버레이 모드에서는 **번역 후 표시**로 표시됩니다.

- 여러 번 눌러도 창은 하나만 유지되며, 기존 창을 앞으로 가져옵니다.
- 항상 위·제목표시줄 숨김·크기 고정은 [분리 버튼 설정](settings.md#분리된-버튼-창)에서 조절합니다.
- 제목표시줄을 숨겼을 때는 버튼을 드래그해 창을 이동합니다.
- 본체가 비정상 종료되어도 분리 버튼은 마지막 확정 영역과 저장된 설정으로 동작합니다.
- 실시간 OCR 실행 중에는 본체와 분리창의 수동 번역 버튼이 잠깁니다.

`설정 → 일반`의 **전역 단축키 사용**을 켜면 다른 창을 보고 있어도 현재 모드의 인식·번역을 실행할 수 있습니다. 기본 사용 상태는 OFF이며 기본 키는 `B`입니다. 입력칸에서 직접 변경할 수 있습니다. 실시간 OCR 실행 중에는 전역 단축키도 잠깁니다.

## 시스템 음성 인식·번역

`음성인식` 탭에서 다음 순서로 실행합니다.

1. **HYTrans 실행**을 누르고 번역 준비가 끝날 때까지 기다립니다.
2. **MekiScript 실행**, **MekiAudioCapture 실행**을 누릅니다.
3. MekiAudioCapture의 **녹음 시작**을 누르고 일본어 음성을 재생합니다.
4. **녹음 종료**를 누릅니다.

기본 일괄 처리는 시스템에서 재생되는 음성을 WASAPI loopback으로 녹음합니다. 종료 후 발화 구간 감지(VAD)와 일본어 음성 인식(STT)을 실행해 원문을 MekiScript에 먼저 표시하고, HYTrans 번역을 순서대로 채웁니다. 작업 중 WAV와 변환 파일은 `MekiAudioCapture.exe` 옆 `work`에 저장하고 처리 후 삭제합니다. 설치 폴더가 읽기 전용이면 쓰기 가능한 보조 경로를 사용합니다.

### 녹음 중 실시간 음성 번역

MekiAudioCapture의 **실시간 음성 번역(저사양에서 비권장)**을 켜면 발화가 확정될 때마다 인식하고 번역합니다. 임시 WAV는 만들지 않습니다. 이 옵션은 녹음이 끝나면 꺼지며 설정 파일에 저장하지 않습니다.

이 기능은 발화를 가능한 속도로 처리하므로 원래 음성과 번역 표시 시각이 맞지 않을 수 있습니다. 저사양 PC에서는 지연이나 일부 실패가 발생할 수 있습니다. 번역이 밀리면 제한된 버퍼를 사용하고, 과부하로 건너뛴 발화는 상태에 표시합니다.

녹음 종료 후에도 남은 항목을 처리합니다. 기다리지 않으려면 **남은 번역 취소**를 누르세요. MekiScript는 최근 2,048개 항목 또는 약 512 KiB의 대본을 유지하며 오래된 내용은 제거합니다.

### 음성 모델

기본 모델은 Parakeet TDT-CTC 0.6B INT8이며 ReazonSpeech FP32/INT8도 선택할 수 있습니다. `설정 → 음성인식`에서 모델과 음성 CHUNK 기준을 바꿉니다.

Lite는 첫 사용 때 선택 모델과 VAD를 공식 sherpa-onnx 릴리스에서 다운로드하고 Full은 포함된 모델을 사용합니다. 모델은 MekiAudioCapture와 MekiSubtitle이 같은 캐시를 사용합니다.

## 영상에서 한국어 SRT 생성

1. `자막 생성` 탭의 **MekiSubtitle 열기**를 누릅니다.
2. 영상 파일과 저장할 SRT 경로를 선택합니다.
3. 작업을 시작합니다. HYTrans는 필요한 경우 자동으로 시작하며 준비될 때까지 기다립니다.

MekiSubtitle은 첫 번째 원본 오디오 스트림의 타임라인을 유지해 추출하고, 일본어 STT와 현재 HYTrans 설정으로 한국어 SRT를 만듭니다. 출력은 UTF-8 BOM입니다.

- 영상 분석에는 빠른 대화용 FAST VAD를 사용합니다. MekiCopy의 음성 CHUNK 설정은 적용하지 않습니다.
- STT/VAD와 번역 모델은 다른 앱과 공유하므로 중복 다운로드하지 않습니다.
- 오디오 추출에 필요한 FFmpeg/FFprobe는 배포본에 포함됩니다.

## 명령줄

소스 실행은 `python mekicopy.py`, 배포본은 `MekiCopy.exe`에 아래 인수를 붙입니다.

| 인수 | 동작 |
|---|---|
| 없음 | 메인 GUI 실행 |
| `--bookmark <이름>` | 지정한 북마크에서 OCR 실행 후 복사 |
| `--pick-bookmark` | 북마크 선택 후 OCR 실행 |
| `--adjust-bookmark <이름>` | 북마크를 영역 선택 화면에서 조정 |

```bat
MekiCopy.exe --bookmark 게임자막
MekiCopy.exe --pick-bookmark
```
