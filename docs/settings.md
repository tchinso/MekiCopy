# 설정과 문제 해결

[처음으로](../README.md) · [사용 안내](usage.md) · [번역 안내](translation.md)

각 작업 화면의 **설정**에서 옵션을 바꾸고 **저장**을 누릅니다.

## 일반

| 옵션 | 동작 |
|---|---|
| MekiCopy가 최소화되면 시스템 트레이로 이동 | 최소화 시 트레이로 이동합니다. 트레이 아이콘을 클릭해 복원합니다. |
| MekiCopy를 항상 위로 | 본체 창을 다른 창 위에 표시합니다. |
| 분리된 '번역 후 표시' 버튼의 제목표시줄 숨김 | 제목표시줄을 숨깁니다. 버튼을 드래그해 창을 이동할 수 있습니다. |
| 번역 서비스 | hdTrans, HY-MT1.5, TranslatorAPI, Cloudflare Workers AI, DeepInfra, Groq 중 선택합니다. 기본값은 hdTrans입니다. |
| API 키 · 모델 목록 · 번역 프롬프트 설정 | 클라우드 서비스별 설정을 편집합니다. |
| hdTrans 설정 · 사전 · 문맥 · 설치 | 엔진 설치와 사용자 사전·문맥을 관리합니다. |
| HYTrans 포트 | 번역 서버 포트입니다. 기본값은 6996입니다. |
| MagPie 실행 시 안내 띄우지 않기 | MagPie 실행 안내를 생략합니다. |
| 오류 분석을 위한 디버그 로그 켜기 | 구성 요소별 처리·통신 로그를 기록합니다. |

## 실시간/수동 번역

| 옵션 | 동작 |
|---|---|
| 실시간 번역 모드 사용 | 켜면 행동 버튼이 **실시간 OCR 시작/중지**, 끄면 **번역 후 표시**가 됩니다. 기본값은 ON입니다. |
| 최소 인식 간격(초) | 0.5 / 1 / 1.5 / 2 / 2.5초 중 선택합니다. 기본값은 1초입니다. |
| 번역 완료를 간단하게 표시하기 | 수동 번역이 끝나면 팝업 대신 버튼에 잠깐 ✓를 표시합니다. |
| 전역 단축키 사용 | 다른 창에서도 수동 번역을 실행합니다. 기본 사용 상태는 OFF입니다. |
| 전역 단축키 설정 | 수동 번역을 실행할 키입니다. 기본값은 `B`입니다. |
| 분리된 '번역 후 표시' 버튼을 항상 위로 | 분리 버튼을 다른 창 위에 표시합니다. |
| 분리된 '번역 후 표시' 버튼의 크기를 고정 | 현재 분리 버튼 창 크기를 고정합니다. |

실시간 번역 모드를 켜면 완료 표시·전역 단축키 사용·단축키 설정·분리 버튼의 항상 위·크기 고정 설정이 비활성화됩니다. 기존 값은 보존되며 수동 번역 모드로 바꾸면 다시 사용할 수 있습니다.

실시간 옵션의 **?**에 마우스를 올리면 안내가 표시됩니다. 저장 후 화면 번역의 `행동`에서 **실시간 OCR 시작**을 누릅니다. [필수 시작 조건](translation.md#실시간-ocr)을 모두 충족해야 합니다.

## 번역 오버레이

| 옵션 | 동작 |
|---|---|
| MekiOverlayer 포트 | 오버레이 서버 포트입니다. 기본값은 6997입니다. |
| 항상 위로 / 제목표시줄 숨김 / 크기 고정 | 오버레이 창 동작을 조절합니다. |
| 배경색깔 | 기본값은 `#111111`입니다. |
| 배경 투명도 | 불투명도를 10~100%로 조절합니다. 기본값은 78%입니다. |
| 글씨 색깔 / 크기 / 폰트 | 기본값은 `#ffffff`, 28pt, Malgun Gothic입니다. 크기는 8~96pt입니다. |

화면 OCR은 항상 HYTrans로 번역해 MekiOverlayer에 표시합니다. 별도로 번역 모드를 켤 필요가 없습니다.

## 음성인식

| 옵션 | 동작 |
|---|---|
| STT 모델 | Parakeet TDT-CTC 0.6B INT8 또는 ReazonSpeech를 선택합니다. |
| ReazonSpeech 정밀도 | FP32 또는 INT8을 선택합니다. Parakeet은 INT8 고정입니다. |
| 음성 CHUNK 기준 | FAST는 짧은 대화 경계, BALANCED는 반응성과 문맥의 균형, LONG은 긴 문맥을 우선합니다. 기본값은 BALANCED입니다. |
| MekiAudioCapture / MekiScript 포트 | 기본값은 각각 6998 / 6999입니다. |
| MekiScript를 항상 위로 | 대본 창을 다른 창 위에 표시합니다. |
| 배경색 / 배경 투명도 | 대본 창의 배경을 조절합니다. |
| 미번역 글씨 색깔·크기·폰트 | 일본어 원문 스타일입니다. 폰트 목록에는 `ー` 글리프가 있는 폰트를 표시합니다. |
| 번역 글씨 색깔·크기·폰트 | 한국어 번역 스타일입니다. |

## 저장 위치

설정과 데이터는 실행 파일 옆 경로를 우선 사용합니다. 설치 폴더가 읽기 전용일 때만 LocalAppData 등 쓰기 가능한 보조 경로를 사용합니다. 로컬 설정이 없으면 LocalAppData에 저장된 설정을 가져옵니다.

| 내용 | 기본 위치 |
|---|---|
| 일반 설정 / 북마크 | `MekiCopy.exe` 옆 `settings.cfg` / `bookmarks.txt` |
| 암호화한 API 설정 | `settings.cfg` 옆 `translation_api.json` |
| 오류 / 디버그 로그 | 각 실행 파일 옆 `error_log/` / `debug_log/` |
| MT1.5 모델 | `HYTrans/models/onnx-community/HY-MT1.5-1.8B-ONNX` |
| hdTrans 엔진·사전 / 사용자 사전 | `HYTrans/hdtrans/installations` / `HYTrans/hdtrans/user` 또는 지정한 외부 파일 |
| 음성·VAD 공용 모델 | `MekiAudioCapture/models` |
| 일괄 음성 처리 임시 파일 | `MekiAudioCapture/work` |

MT1.5 모델은 고정 리비전·크기·SHA-256으로 검증합니다. 중단된 `.part` 다운로드는 이어받으며 체크섬이 일치하는 파일만 게시합니다. MekiSubtitle은 번역·음성 공용 모델 캐시를 사용합니다.

## 문제 해결

| 증상 | 확인할 내용 |
|---|---|
| OCR이 비거나 실패함 | 텍스트 주변 여백을 포함해 영역을 넓히고 확정했는지 확인합니다. |
| 번역이 시작되지 않음 | 화면 번역의 **모든 도구 연결 상태 확인**으로 HYTrans와 MekiOverlayer 상태를 확인합니다. 초기 모델 준비가 끝날 때까지 기다립니다. |
| 실시간 OCR 시작이 비활성화됨 | [세 가지 시작 조건](translation.md#실시간-ocr)을 확인하고 설정을 저장합니다. |
| TranslatorAPI 모델 준비가 멈춤 | 표시된 브라우저 창의 **모델 시작**을 누르고 번역하는 동안 창을 열어 둡니다. |
| 포트 사용 오류 | 네 서비스의 포트가 서로 다르고 다른 프로그램에서도 사용하지 않는지 확인합니다. |
| API 번역 실패 | 키·Account ID·모델 ID·서비스 사용량 제한을 확인합니다. 시간 초과·빈 응답·잘린 응답도 오류로 표시합니다. |
| 프로그램 또는 창이 멈춤 | 구성 요소의 `error_log/`를 확인합니다. 재현 과정이 필요하면 디버그 로그를 켭니다. |

오류·미처리 예외·HTTP/IPC 실패·창 없는 EXE의 stderr는 디버그 옵션과 관계없이 오류 로그에 기록합니다.

MekiCopy가 직접 실행한 도구는 HTTP 상태와 GUI 응답을 감시하며, 연속 실패하면 해당 프로세스를 재시작합니다. 진행 중인 녹음이나 번역은 중단될 수 있습니다. 사용자가 별도로 실행한 도구는 자동으로 종료·재시작하지 않습니다.

NVIDIA CUDA를 사용할 수 없으면 OCR은 진단 로그를 남기고 CPU로 실행합니다. MT1.5는 WebGPU를 사용할 수 없을 때 CPU/WASM을 사용합니다. 로컬 번역 제한 시간은 입력 길이에 따라 120~600초입니다.

Tcl/Tk가 한글 실행 경로를 읽을 수 없으면 실행 파일 옆 `MekiCopyRuntime`으로 런타임을 준비하고, 그 경로도 사용할 수 없을 때 LocalAppData 또는 임시 폴더를 사용합니다.

## 실행 환경

| 항목 | 최소 | 권장 |
|---|---|---|
| OS | Windows 10 2004 이상 | Windows 10 2004 이상 |
| CPU | Intel Core i5-6500 / Ryzen 3 1200급 | Intel Core i5-8400 / Ryzen 5 2600급 |
| RAM | 8GB | 16GB |
| GPU | 필수 아님 | VRAM 6GB 이상 |

소스 실행에는 Python 3.12~3.14와 Tcl/Tk가 필요합니다. `install_mekiocr.bat`으로 고정 의존성을 설치하고 `run_mekicopy.bat` 또는 `python mekicopy.py`로 실행합니다.
