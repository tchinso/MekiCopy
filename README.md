# MekiCopy

화면의 일본어와 스피커에서 나오는 음성을 한국어로 번역하고, 영상 파일의 한국어 SRT 자막을 만드는 Windows 도구입니다.

![MekiCopy 미리보기](preview.png)

## 설치

[Releases에서 다운로드](https://github.com/tchinso/MekiCopy/releases)한 ZIP을 압축 해제하고 `Start-MekiCopy.bat`을 실행하세요. `MekiCopy/MekiCopy.exe`를 직접 실행해도 됩니다. Python은 별도로 설치하지 않아도 됩니다.

| 배포판 | 포함 내용 | 처음 사용할 때 |
|---|---|---|
| **Lite** | 모든 앱과 번역 기능 | 필요한 엔진·사전·모델을 다운로드합니다. GPU OCR에는 CUDA/cuDNN, 영상 자막에는 FFmpeg를 처음 사용할 때 설치합니다. MagPie도 필요할 때 설치합니다. |
| **Full** | Lite + CUDA/cuDNN·FFmpeg, hdTrans 엔진·기본 사전, OCR·MT1.5·음성/VAD 모델, MagPie | 포함된 구성요소를 바로 사용하며 hdTrans는 오프라인 번역이 가능합니다. |

두 배포판의 기능과 실행 파일은 같습니다. TranslatorAPI 언어 모델은 브라우저에서 관리하므로 Full에도 포함되지 않습니다.

Lite의 GPU 구성요소는 사용 가능한 NVIDIA GPU가 있을 때만 내려받습니다. 다운로드가 실패하면 CPU OCR로 실행합니다. 받은 GPU·영상 도구는 검증된 캐시에 보관하여 다음 실행부터 재사용합니다.

- Windows 10 2004 이상, RAM 8GB 이상이 필요하며 16GB 이상을 권장합니다.
- OCR은 CPU로 실행할 수 있으며, 사용 가능한 NVIDIA CUDA 환경에서는 GPU를 사용합니다.
- MT1.5와 TranslatorAPI 번역은 Chrome 또는 Edge가 필요합니다. hdTrans와 클라우드 API 번역에는 브라우저가 필요하지 않습니다.

## 빠른 시작

앱을 켜면 **무엇을 번역하시겠어요?** 화면에서 작업을 선택합니다.

| 선택 | 열리는 화면 |
|---|---|
| 화면에 나오는 일본어를 번역 | 영역 설정·캡쳐 설정·도구·행동·설정 |
| 스피커에서 나오는 음성을 번역 | 녹음 엔진·번역 엔진·번역결과 표시기 실행과 연결 상태 확인·설정 |
| 영상 파일에 대한 자막 생성 | 자막 제작 도구 열기·설정 |

화면 번역을 선택했다면 다음 순서로 준비합니다.

1. `설정 → 일반`에서 번역 서비스를 선택합니다. 기본값은 **hdTrans**입니다.
2. `도구`에서 **번역 엔진 실행**, **번역결과 표시기 실행**을 누르고 준비될 때까지 기다립니다.
3. `영역 설정`에서 **임시 영역 선택**을 누르고 일본어가 있는 곳을 드래그합니다.
4. 위치와 크기를 조절한 뒤 `Enter`로 선택하고 **임시 영역을 확정**을 누릅니다. `Esc`는 취소입니다.
5. `행동`에서 **실시간 OCR 시작** 또는 **번역 후 표시**를 누릅니다.

번역 엔진은 HYTrans, 화면 번역결과 표시기는 MekiOverlayer입니다. **모든 도구 연결 상태 확인**으로 두 도구의 준비 상태를 확인합니다. 자주 쓰는 영역은 북마크로 저장할 수 있습니다.

## 수동 번역과 실시간 번역

`설정 → 실시간/수동 번역`의 **실시간 번역 모드 사용**으로 행동 버튼을 선택합니다.

- 끄면 **번역 후 표시**를 누를 때마다 확정 영역을 한 번 번역합니다.
- 켜면 **실시간 OCR 시작**으로 반복 번역하고 **실시간 OCR 중지**로 멈춥니다. 기본값은 사용 ON입니다.

최소 인식 간격은 기본 **1초**이며 **0.5 / 1 / 1.5 / 2 / 2.5초** 중 선택할 수 있습니다. 실시간 번역에는 확정 영역과 준비된 HYTrans·MekiOverlayer가 필요합니다. 앱을 다시 열거나 도구 연결이 복구되어도 자동 시작하지 않습니다.

실시간 번역 모드에서는 수동 번역의 완료 표시·전역 단축키·분리 버튼 관련 설정이 비활성화됩니다. OCR 결과는 번역해서 표시하며 클립보드로 복사하지 않습니다.

## 소리 번역과 영상 자막 생성

| 작업 | 시작 방법 |
|---|---|
| 시스템 음성 인식·번역 | 소리 번역 화면에서 **녹음 엔진 실행**(MekiAudioCapture), **번역 엔진 실행**(HYTrans), **번역결과 표시기 실행**(MekiScript)을 누른 뒤 녹음을 시작·종료합니다. |
| 녹음 중 발화별 번역 | MekiAudioCapture에서 **실시간 음성 번역**을 켜고 녹음합니다. 저사양 PC에서는 지연될 수 있습니다. |
| 영상에서 한국어 SRT 생성 | 영상 자막 생성 화면에서 **자막 제작 도구 열기**(MekiSubtitle)를 누르고 영상과 출력 경로를 선택합니다. |
